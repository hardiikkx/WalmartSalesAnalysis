# 🛒 Walmart Sales Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing Walmart sales data using **MySQL** to uncover meaningful business insights related to sales performance, product lines, customer behavior, payment methods, and customer ratings.

The project involves creating a database, performing feature engineering, and conducting Exploratory Data Analysis (EDA) to answer business-related questions using SQL queries.

The goal is to demonstrate practical SQL skills and the ability to transform raw sales data into meaningful information that supports data-driven business decisions.

## 🎯 Project Objectives

- Analyze sales performance across different cities and branches.
- Identify the most popular product lines and payment methods.
- Evaluate monthly revenue and Cost of Goods Sold (COGS).
- Understand customer purchasing behavior and demographics.
- Analyze customer ratings across product lines, branches, and time periods.
- Perform feature engineering to extract additional information from existing data.
- Practice SQL queries to solve real-world business problems.

- **Database:** MySQL

## ⚙️ Feature Engineering

Feature engineering was performed using SQL to create additional columns that make the data more useful for analysis.

### 1. Time of Day

Created a `time_of_day` column using a `CASE` statement to categorize transactions into three time periods:

- Morning
- Afternoon
- Evening

```sql
ALTER TABLE sales
ADD COLUMN time_of_day VARCHAR(20);

UPDATE sales
SET time_of_day =
    CASE
        WHEN time BETWEEN '00:00:00' AND '11:59:59'
            THEN 'Morning'
        WHEN time BETWEEN '12:00:00' AND '15:59:59'
            THEN 'Afternoon'
        ELSE 'Evening'
    END;
```

### 2. Day Name

Created a `day_name` column to identify the day of the week for each transaction.

```sql
ALTER TABLE sales
ADD COLUMN day_name VARCHAR(15);

UPDATE sales
SET day_name = DAYNAME(date);
```

### 3. Month Name

Created a `month_name` column to extract the month from the transaction date.

```sql
ALTER TABLE sales
ADD COLUMN month_name VARCHAR(10);

UPDATE sales
SET month_name = MONTHNAME(date);
```

These new columns allow sales performance to be analyzed by time of day, day of the week, and month.

## 📊 Exploratory Data Analysis (EDA)

The project explores three major areas of business performance.

### 1. Product Analysis

The following business questions were investigated:

- How many unique product lines are present in the dataset?
- Which product line generates the highest revenue?
- Which product line sells the most units?
- Which product line has the highest average VAT?
- Which product line receives the highest average customer rating?
- Which product lines perform above or below average sales?

**Business value:** Helps identify popular products, high-revenue categories, and opportunities to improve product performance.

### 2. Sales Analysis

The analysis investigates:

- What is the total revenue generated by each month?
- Which month has the highest COGS?
- Which city generates the highest revenue?
- Which branch sells the most units?
- Which customer type contributes the most revenue?
- How many sales occur during different times of the day?
- Which days of the week have the highest sales activity?

**Business value:** Helps evaluate sales performance, identify high-performing locations, and understand temporal sales patterns.

### 3. Customer Analysis

The project explores:

- How many unique customer types are present?
- What are the available payment methods?
- Which customer type appears most frequently?
- Which customer type makes the most purchases?
- What is the gender distribution of customers?
- How is the gender distribution different across branches?
- Which time of day receives the highest average customer rating?
- Which day of the week has the highest average rating?
- How do customer ratings vary across branches?

**Business value:** Helps understand customer purchasing patterns, payment preferences, and satisfaction levels.
